Entry: **🏝️** — 2 characters, one emoji.

One small island, and the whole holiday is in the picture: warm sea,
white sand, and an inbox that cannot reach you. Show it to a stranger
and they start checking flights before they finish reading the sentence.

## Run

```sh
python3 main.py
```

No network, no arguments, no secrets. The program writes the emoji to
`/output/entry.txt`.
